# Audran Films

Page d'accueil du portfolio de photographies argentiques d'Audran.

Le site est volontairement léger : HTML, CSS et JavaScript sans dépendances. Les photographies disposées sur la droite peuvent être déplacées à la souris, au toucher ou au clavier.

## Aperçu

Le site est publié automatiquement avec GitHub Pages à chaque mise à jour de la branche `main`.
